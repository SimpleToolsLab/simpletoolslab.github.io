# SimpleToolsLab

Browser-based word counter, character counter and text case converter, plus a practical writing guide.

## Deployment
Upload all files to the root of the `simpletoolslab.github.io` GitHub Pages repository. Keep `index.html`, `style.css`, `script.js`, and `tools.js` in the same folder.

## Notes
Word counting and document extraction run client-side. The word counter uses Mammoth.js for DOCX and PDF.js for PDF extraction. Scanned PDF OCR is not supported.

## Before publishing
Review the Privacy and Contact pages, confirm external third-party scripts, and test uploads and mobile navigation. AdSense approval is not guaranteed.
