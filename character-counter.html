When to use character counts

Character limits are common in application forms, profile descriptions, search snippets and short messages. A character count usually includes spaces and punctuation, but different platforms may use different rules for emoji and combined characters.

Example: a 280-character limit

Set the limit to 280, paste your draft, and watch the remaining count. If the number is negative, shorten the text before submitting it. The counter uses JavaScript Unicode code points, which can differ from how a particular website counts emoji.

Characters versus words

“A short note” contains three words but twelve characters including spaces. Use a word counter when the requirement is expressed in words, and a character counter when the requirement is expressed in characters.
